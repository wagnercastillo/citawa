# Etapa 1 — Base: monorepo, auth, superadmin y usuarios — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar funcionando el monorepo con una API NestJS y un panel Next.js donde el superadmin crea consultorios, el dueño activa su cuenta con una invitación e invita a recepcionistas, todo con login por cookie y aislamiento entre consultorios.

**Architecture:** Monorepo con npm workspaces (`apps/api`, `apps/web`). La API (NestJS + TypeORM + PostgreSQL) expone `/api/*` con JWT en cookie httpOnly. El guard global carga el usuario desde la base de datos en cada request, y el `clinic_id` siempre sale del usuario autenticado. El panel (Next.js 15) llama a `/api/*` en su propio dominio y una rewrite de Next lo reenvía a la API, así la cookie es de primera parte.

**Tech Stack:** Node 24, npm workspaces, NestJS 11, TypeORM 0.3, PostgreSQL 16 (Docker), bcryptjs, @nestjs/jwt, @nestjs/throttler, class-validator, Jest 29 + supertest, Next.js 15 (App Router) + Tailwind + shadcn/ui.

**Spec:** `docs/superpowers/specs/2026-10-05-recepcionista-wa-design.md` (cubre §2, §3 reglas transversales, §4 tablas `clinics` y `users`, §5.5 paso 1–2, §6 `/admin` y usuarios de `/app/settings`, §7 seguridad).

## Global Constraints

- Prefijo global de la API: `api` (rutas `/api/...`); nunca poner `api` dentro de `@Controller()`.
- Claves `uuid` (`gen_random_uuid()`), columnas `created_at`/`updated_at` `timestamptz`, nombres de columnas en snake_case.
- Roles: `SUPERADMIN | OWNER | RECEPTION`; `clinic_id` es NULL solo para SUPERADMIN.
- Estados de suscripción: `ACTIVE | PAST_DUE | SUSPENDED`.
- Zona horaria por defecto del consultorio: `America/Lima`.
- Invitación: token de un solo uso, válido 72 h; en la base de datos solo se guarda su hash SHA-256.
- JWT en cookie `session`: httpOnly, `SameSite=Lax`, `Secure` en producción, 7 días.
- El `clinic_id` nunca se acepta desde el cliente (ni en el body ni en la URL); siempre viene del usuario autenticado.
- Contraseñas: bcrypt, de 8 a 72 caracteres.
- Errores de la API: formato `{ statusCode, message, error }`, con mensajes en español.
- Emails: siempre `trim().toLowerCase()` antes de guardar o comparar.
- **Desviación del spec (consciente):** en esta etapa el enlace de invitación **se devuelve en la respuesta y se muestra en el panel para copiarlo**, en vez de enviarse por correo. El envío por correo queda para más adelante.

## Review Focus

1. **Email con mayúsculas o espacios** (`" Ana@Mail.com "`) al invitar → el login con `ana@mail.com` debe funcionar. Test en Task 4.
2. **Enlace de invitación vencido o ya usado** → error claro ("Invitación inválida o vencida"), sin crear sesión. Tests en Task 4.
3. **Usuario desactivado que todavía tiene la cookie válida** → la próxima request devuelve 401. Test en Task 3.
4. **Dueño del consultorio A que actúa sobre un usuario del consultorio B por id** → 404, sin efectos. Test en Task 5.
5. **Escalada de privilegios por el body** (enviar `role: "OWNER"` o `clinicId` al invitar) → 400 por propiedades no permitidas. Test en Task 5.

`apps/api/src/common/all-exceptions.filter.ts`:
```ts
import { ArgumentsHost, Catch, ExceptionFilter, HttpException, HttpStatus, Logger } from '@nestjs/common';
import { Response } from 'express';
import { QueryFailedError } from 'typeorm';

@Catch()
export class AllExceptionsFilter implements ExceptionFilter {
  private readonly logger = new Logger('Exceptions');

  catch(exception: unknown, host: ArgumentsHost): void {
    const res = host.switchToHttp().getResponse<Response>();

    if (exception instanceof HttpException) {
      const status = exception.getStatus();
      const body = exception.getResponse();
      const message =
        typeof body === 'string' ? body : ((body as { message?: unknown }).message ?? exception.message);
      res.status(status).json({ statusCode: status, message, error: HttpStatus[status] });
      return;
    }

    if (exception instanceof QueryFailedError && (exception as QueryFailedError & { code?: string }).code === '23505') {
      res.status(409).json({ statusCode: 409, message: 'Ya existe un registro con esos datos', error: 'CONFLICT' });
      return;
    }

    this.logger.error(exception);
    res.status(500).json({ statusCode: 500, message: 'Error interno del servidor', error: 'INTERNAL_SERVER_ERROR' });
  }
}
```

```ts
import { createHash, randomBytes } from 'crypto';

export const INVITE_TTL_MS = 72 * 60 * 60 * 1000;

export function hashInviteToken(token: string): string {
  return createHash('sha256').update(token).digest('hex');
}

export function newInviteToken(now: Date = new Date()): { token: string; hash: string; expiresAt: Date } {
  const token = randomBytes(32).toString('base64url');
  return { token, hash: hashInviteToken(token), expiresAt: new Date(now.getTime() + INVITE_TTL_MS) };
}
```

  data: { email: string; role: Role; clinicId?: string | null; password?: string; name?: string; active?: boolean },

  const repo = app.get(DataSource).getRepository(User);
  return repo.save(

      name: data.name ?? 'Usuario',
      role: data.role,

import { CanActivate, ExecutionContext, Injectable, UnauthorizedException } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { JwtService } from '@nestjs/jwt';
import { InjectRepository } from '@nestjs/typeorm';
import { Request } from 'express';
import { Repository } from 'typeorm';
import { User } from '../users/user.entity';
import { IS_PUBLIC } from './decorators';
import { SESSION_COOKIE } from './session';

@Injectable()
export class JwtAuthGuard implements CanActivate {
  constructor(
    private readonly reflector: Reflector,
    private readonly jwt: JwtService,
    @InjectRepository(User) private readonly users: Repository<User>,
  ) {}

  async canActivate(ctx: ExecutionContext): Promise<boolean> {
    if (this.reflector.getAllAndOverride<boolean>(IS_PUBLIC, [ctx.getHandler(), ctx.getClass()])) return true;

    const req = ctx.switchToHttp().getRequest<Request>();
    const token: string | undefined = req.cookies?.[SESSION_COOKIE];
    if (!token) throw new UnauthorizedException('Sesión no iniciada');

    let sub: string;
    try {
      ({ sub } = await this.jwt.verifyAsync<{ sub: string }>(token));
    } catch {
      throw new UnauthorizedException('Sesión inválida o expirada');
    }

    const user = await this.users.findOne({ where: { id: sub, active: true } });
    if (!user || !user.passwordHash) throw new UnauthorizedException('Sesión inválida o expirada');

    req.user = { id: user.id, role: user.role, clinicId: user.clinicId, name: user.name, email: user.email };
    return true;
  }
}

import { BadRequestException, Injectable, NotFoundException, UnauthorizedException } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import { InjectRepository } from '@nestjs/typeorm';
import * as bcrypt from 'bcryptjs';
import { Repository } from 'typeorm';
import { SubscriptionStatus } from '../clinics/clinic.entity';
import { Role } from '../users/role.enum';
import { User } from '../users/user.entity';
import { hashInviteToken } from './invite-token';

export interface MeResponse {
  id: string;
  name: string;
  email: string;
  role: Role;
  clinic: { id: string; name: string; subscriptionStatus: SubscriptionStatus } | null;
}

@Injectable()
export class AuthService {
  constructor(
    @InjectRepository(User) private readonly users: Repository<User>,
    private readonly jwt: JwtService,
  ) {}

  async login(email: string, password: string): Promise<{ token: string; me: MeResponse }> {
    const user = await this.users.findOne({ where: { email } });
    const ok = !!user && user.active && !!user.passwordHash && (await bcrypt.compare(password, user.passwordHash));
    if (!ok) throw new UnauthorizedException('Email o contraseña incorrectos');
    return { token: await this.sign(user!), me: await this.me(user!.id) };
  }

  async inviteInfo(token: string): Promise<{ name: string; email: string }> {
    const user = await this.findValidInvite(token);
    if (!user) throw new NotFoundException('Invitación inválida o vencida');
    return { name: user.name, email: user.email };
  }

  async acceptInvite(token: string, password: string): Promise<{ token: string; me: MeResponse }> {
    const user = await this.findValidInvite(token);
    if (!user) throw new BadRequestException('Invitación inválida o vencida');
    user.passwordHash = await bcrypt.hash(password, 10);
    user.inviteTokenHash = null;
    user.inviteExpiresAt = null;
    await this.users.save(user);
    return { token: await this.sign(user), me: await this.me(user.id) };
  }

  async me(userId: string): Promise<MeResponse> {
    const u = await this.users.findOneOrFail({ where: { id: userId }, relations: { clinic: true } });
    return {
      id: u.id,
      name: u.name,
      email: u.email,
      role: u.role,
      clinic: u.clinic ? { id: u.clinic.id, name: u.clinic.name, subscriptionStatus: u.clinic.subscriptionStatus } : null,
    };
  }

  private async findValidInvite(token: string): Promise<User | null> {
    const user = await this.users.findOne({ where: { inviteTokenHash: hashInviteToken(token) } });
    if (!user || !user.active || !user.inviteExpiresAt || user.inviteExpiresAt.getTime() < Date.now()) return null;
    return user;
  }

  private sign(user: User): Promise<string> {
    return this.jwt.signAsync({ sub: user.id });
  }
}

import { Body, Controller, Get, HttpCode, Param, Post, Res, UseGuards } from '@nestjs/common';
import { ThrottlerGuard } from '@nestjs/throttler';
import { Response } from 'express';
import { AcceptInviteDto, LoginDto } from './auth.dto';
import { AuthService, MeResponse } from './auth.service';
import { CurrentUser, Public } from './decorators';
import { AuthUser, SESSION_COOKIE, sessionCookieOptions } from './session';

@Controller('auth')
export class AuthController {
  constructor(private readonly auth: AuthService) {}

  @Public()
  @UseGuards(ThrottlerGuard)
  @Post('login')
  @HttpCode(200)
  async login(@Body() dto: LoginDto, @Res({ passthrough: true }) res: Response): Promise<MeResponse> {
    const { token, me } = await this.auth.login(dto.email, dto.password);
    res.cookie(SESSION_COOKIE, token, sessionCookieOptions());
    return me;
  }

  @Public()
  @Post('logout')
  @HttpCode(204)
  logout(@Res({ passthrough: true }) res: Response): void {
    res.clearCookie(SESSION_COOKIE, { path: '/' });

  @Get('me')

    return this.auth.me(user.id);

  @Post('invite/accept')

import { BadRequestException, ConflictException, Injectable, NotFoundException } from '@nestjs/common';
import { InjectDataSource } from '@nestjs/typeorm';
import { DataSource, In } from 'typeorm';
import { InvitesService } from '../auth/invites.service';
import { Clinic, SubscriptionStatus } from '../clinics/clinic.entity';
import { PublicUser, toPublicUser } from '../users/public-user';
import { Role } from '../users/role.enum';
import { User } from '../users/user.entity';
import { CreateClinicDto, UpdateClinicDto } from './admin.dto';

export interface ClinicRow {
  id: string;
  name: string;
  address: string | null;
  subscriptionStatus: SubscriptionStatus;
  paidUntil: string | null;
  owner: PublicUser | null;
}

const toRow = (c: Clinic, owner?: User): ClinicRow => ({
  id: c.id,
  name: c.name,
  address: c.address,
  subscriptionStatus: c.subscriptionStatus,
  paidUntil: c.paidUntil,
  owner: owner ? toPublicUser(owner) : null,
});

@Injectable()
export class AdminService {
  constructor(@InjectDataSource() private readonly ds: DataSource, private readonly invites: InvitesService) {}

  async list(): Promise<ClinicRow[]> {
    const clinics = await this.ds.getRepository(Clinic).find({ order: { createdAt: 'DESC' } });
    if (!clinics.length) return [];
    const owners = await this.ds
      .getRepository(User)
      .find({ where: { role: Role.OWNER, clinicId: In(clinics.map((c) => c.id)) }, order: { createdAt: 'ASC' } });
    return clinics.map((c) => toRow(c, owners.find((o) => o.clinicId === c.id)));
  }

  create(dto: CreateClinicDto): Promise<{ clinic: ClinicRow; inviteUrl: string }> {
    return this.ds.transaction(async (m) => {
      if (await m.findOne(User, { where: { email: dto.ownerEmail } })) {
        throw new ConflictException('Ya existe un usuario con ese email');
      }
      const clinic = await m.save(m.create(Clinic, { name: dto.name, address: dto.address ?? null }));
      const owner = m.create(User, { name: dto.ownerName, email: dto.ownerEmail, role: Role.OWNER, clinicId: clinic.id });
      const inviteUrl = this.invites.prepare(owner);
      await m.save(owner);
      return { clinic: toRow(clinic, owner), inviteUrl };
    });
  }

  async update(id: string, dto: UpdateClinicDto): Promise<ClinicRow> {
    const repo = this.ds.getRepository(Clinic);
    const clinic = await repo.findOne({ where: { id } });
    if (!clinic) throw new NotFoundException('Consultorio no encontrado');
    clinic.paidUntil = dto.paidUntil;
    await repo.save(clinic);
    const owner = await this.ds.getRepository(User).findOne({ where: { clinicId: id, role: Role.OWNER } });
    return toRow(clinic, owner ?? undefined);
  }

  async reinviteOwner(clinicId: string): Promise<{ inviteUrl: string }> {
    const repo = this.ds.getRepository(User);
    const owner = await repo.findOne({ where: { clinicId, role: Role.OWNER }, order: { createdAt: 'ASC' } });
    if (!owner) throw new NotFoundException('Consultorio no encontrado');
    if (owner.passwordHash) throw new BadRequestException('El dueño ya activó su cuenta');
    const inviteUrl = this.invites.prepare(owner);
    await repo.save(owner);
    return { inviteUrl };
  }
}

import { BadRequestException, ConflictException, Injectable, NotFoundException } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { InvitesService } from '../auth/invites.service';
import { PublicUser, toPublicUser } from './public-user';
import { Role } from './role.enum';
import { User } from './user.entity';
import { InviteUserDto } from './users.dto';

@Injectable()
export class UsersService {
  constructor(@InjectRepository(User) private readonly users: Repository<User>, private readonly invites: InvitesService) {}

  async list(clinicId: string): Promise<PublicUser[]> {
    const rows = await this.users.find({ where: { clinicId }, order: { createdAt: 'ASC' } });
    return rows.map(toPublicUser);
  }

  async invite(clinicId: string, dto: InviteUserDto): Promise<{ user: PublicUser; inviteUrl: string }> {
    if (await this.users.findOne({ where: { email: dto.email } })) {
      throw new ConflictException('Ya existe un usuario con ese email');
    }
    const user = this.users.create({ name: dto.name, email: dto.email, role: Role.RECEPTION, clinicId });
    const inviteUrl = this.invites.prepare(user);
    await this.users.save(user);
    return { user: toPublicUser(user), inviteUrl };
  }

  async setActive(clinicId: string, actorId: string, userId: string, active: boolean): Promise<PublicUser> {
    const user = await this.findInClinic(clinicId, userId);
    if (user.id === actorId) throw new BadRequestException('No puedes desactivarte a ti mismo');
    user.active = active;
    await this.users.save(user);
    return toPublicUser(user);
  }

  async reinvite(clinicId: string, userId: string): Promise<{ inviteUrl: string }> {
    const user = await this.findInClinic(clinicId, userId);
    if (user.passwordHash) throw new BadRequestException('Este usuario ya activó su cuenta');
    const inviteUrl = this.invites.prepare(user);
    await this.users.save(user);
    return { inviteUrl };
  }

export class ApiError extends Error {
  constructor(public readonly status: number, message: string) {
    super(message);
  }
}

export async function api<T>(path: string, init: RequestInit = {}): Promise<T> {
  const res = await fetch(`/api${path}`, {
    ...init,
    credentials: 'include',
    headers: { 'Content-Type': 'application/json', ...init.headers },
  });
  if (res.status === 204) return undefined as T;
  const body = await res.json().catch(() => ({}));
  if (!res.ok) {
    const message = Array.isArray(body.message) ? body.message.join('. ') : (body.message ?? 'Error inesperado');
    throw new ApiError(res.status, message);
  }
  return body as T;
}

import { useRouter } from 'next/navigation';

export function homeFor(role: Role): '/admin' | '/app' {
  return role === 'SUPERADMIN' ? '/admin' : '/app';
}

export function useMe(): Me | null {
  const router = useRouter();
  const [me, setMe] = useState<Me | null>(null);
  useEffect(() => {
    api<Me>('/auth/me')
      .then(setMe)
      .catch((e) => {
        if (e instanceof ApiError && e.status === 401) router.replace('/login');
      });
  }, [router]);
  return me;
}

- [ ] **Step 2: Página de usuarios (solo OWNER)**

`apps/web/src/app/app/users/page.tsx`:
```tsx
'use client';

import Link from 'next/link';
import { useRouter } from 'next/navigation';
import { FormEvent, useCallback, useEffect, useState } from 'react';
import { Button } from '@/components/ui/button';
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card';
import { Input } from '@/components/ui/input';
import { Label } from '@/components/ui/label';
import { api } from '@/lib/api';
import type { PublicUser } from '@/lib/types';
import { useMe } from '@/lib/use-me';

export default function UsersPage() {
  const me = useMe();
  const router = useRouter();
  const [users, setUsers] = useState<PublicUser[]>([]);
  const [inviteUrl, setInviteUrl] = useState('');
  const [error, setError] = useState('');

  const load = useCallback(() => {
    api<PublicUser[]>('/users').then(setUsers).catch((e) => setError((e as Error).message));
  }, []);

  useEffect(() => {
    if (!me) return;
    if (me.role !== 'OWNER') router.replace(me.role === 'SUPERADMIN' ? '/admin' : '/app');
    else load();
  }, [me, router, load]);

  async function run(action: () => Promise<unknown>) {
    setError('');
    try {
      await action();
      load();
    } catch (e) {
      setError((e as Error).message);
    }
  }

  async function onInvite(e: FormEvent<HTMLFormElement>) {
    e.preventDefault();
    const formEl = e.currentTarget;
    const form = new FormData(formEl);
    await run(async () => {
      const res = await api<{ inviteUrl: string }>('/users/invite', {
        method: 'POST',
        body: JSON.stringify({ name: form.get('name'), email: form.get('email') }),
      });
      setInviteUrl(res.inviteUrl);
      formEl.reset();
    });
  }

  if (!me || me.role !== 'OWNER') return <p className="p-8 text-slate-500">Cargando…</p>;

  return (
    <main className="mx-auto max-w-3xl space-y-6 p-4">
      <header className="flex items-center justify-between">
        <h1 className="text-xl font-bold">Usuarios</h1>
        <Link href="/app" className="text-sm underline">Volver</Link>
      </header>

      <Card>
        <CardHeader>
          <CardTitle className="text-base">Invitar recepcionista</CardTitle>
        </CardHeader>
        <CardContent>
          <form onSubmit={onInvite} className="grid gap-3 sm:grid-cols-3">
            <div className="space-y-1">
              <Label htmlFor="name">Nombre</Label>
              <Input id="name" name="name" required minLength={2} />
            </div>
            <div className="space-y-1">
              <Label htmlFor="email">Email</Label>
              <Input id="email" name="email" type="email" required />
            </div>
            <div className="flex items-end">
              <Button type="submit">Invitar</Button>
            </div>
          </form>
          {inviteUrl && (
            <div className="mt-4 flex items-center gap-2 rounded border border-emerald-300 bg-emerald-50 p-2 text-sm">
              <span className="truncate">{inviteUrl}</span>
              <Button size="sm" variant="outline" onClick={() => navigator.clipboard.writeText(inviteUrl)}>Copiar</Button>
            </div>
          )}
          {error && <p className="mt-2 text-sm text-red-600">{error}</p>}
        </CardContent>
      </Card>

      <ul className="divide-y rounded-lg border bg-white">
        {users.map((u) => (
          <li key={u.id} className="flex flex-wrap items-center justify-between gap-2 p-3">
            <div>
              <p className="font-medium">
                {u.name} <span className="text-xs text-slate-500">({u.role === 'OWNER' ? 'Dueño' : 'Recepción'})</span>
              </p>
              <p className="text-sm text-slate-500">
                {u.email}
                {u.pending && ' · invitación pendiente'}
                {!u.active && ' · desactivado'}
              </p>
            </div>
            {u.id !== me.id && (
              <div className="flex gap-2">
                {u.pending && (
                  <Button
                    size="sm"
                    variant="outline"
                    onClick={() =>
                      run(async () => {
                        const res = await api<{ inviteUrl: string }>(`/users/${u.id}/reinvite`, { method: 'POST' });
                        setInviteUrl(res.inviteUrl);
                      })
                    }
                  >
                    Nuevo enlace
                  </Button>
                )}
                <Button
                  size="sm"
                  variant={u.active ? 'destructive' : 'default'}
                  onClick={() =>
                    run(() => api(`/users/${u.id}`, { method: 'PATCH', body: JSON.stringify({ active: !u.active }) }))
                  }
                >
                  {u.active ? 'Desactivar' : 'Activar'}
                </Button>
              </div>
            )}
          </li>
        ))}
      </ul>
    </main>
  );
}
```
